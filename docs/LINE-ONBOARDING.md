# LINE onboarding และวิธีใช้ที่เรียกดูได้ทุกเมื่อ

เพิ่มเพื่อน OA (`follow`) จะตอบ Flex Carousel 10 ใบจาก `lib/line/onboarding.ts` เรียง เริ่มใช้ → จด/สแกน → รายรับ → ลองก่อนจ่าย → หมวด/งบ → บิล/ผ่อน → สรุป/วิเคราะห์ → แต้ม → แจ้งเตือน → โปรตัวอย่าง ทุกปุ่มคู่มืออ่านคำอธิบายเท่านั้น ไม่ตั้งรอบ บันทึกเงิน แจกแต้ม หรือเปิดการแจ้งเตือนเอง

เรียกซ้ำได้ด้วย `ขอวิธีใช้`, `ขอวิธีใช้งานหน่อยครับ`, `คู่มือ`, `ช่วยสอนหน่อย`, `ใช้ยังไง`, `ไม่รู้วิธีใช้` หรือเจาะหัวข้อ เช่น `จดรายรับยังไง`, `ขอวิธีผ่อน`, `ขอวิธีตั้งงบ`, `ลบรายการยังไง`, `ขอวิธีส่งสลิป`, `ทำยังไงถึงได้แต้ม` มีคำอธิบายเพิ่มเรื่องปรับยอด ค่าใช้จ่ายจำเป็น วันรับเงิน เงินเผื่อ การเตือนจด และข้อมูลส่วนตัว

ตัวจำแนก how-to ทำงานก่อนอ่าน pending state ทุกชนิด จึงใช้ได้ระหว่างถามยอด แก้รายการ ตั้งรอบเงิน หรือรอยืนยัน ตัวอย่างยอดในคำถามวิธีใช้ไม่ถูกลงบัญชี คำตอบคู่มือเคลียร์ pending ของข้อความถัดไป การพิมพ์ตัวเลขหรือคำว่า ยืนยัน หลังอ่านคู่มือจะไม่ยืนยันร่างเก่าโดยปริยาย ปุ่มยืนยันเก่ายังใช้กฎ nonce/เจ้าของ/อายุ/ข้อมูลล่าสุดเดิมเมื่อผู้ใช้ตั้งใจกด

ข้อความตอบกลับมีปุ่ม วิธีใช้ ใน quick reply หากยังมีที่ว่าง โดยไม่ทิ้งปุ่มการเงินและไม่เกิน 13 ปุ่ม ถ้าปุ่มเต็มยังพิมพ์ขอวิธีใช้ได้เสมอ คำขอทั่วไป เช่น `ข้าว 50`, `ช่วยจดข้าว 50`, `ได้รับเงิน 1000 บาท`, `ชาบู 199 ไหวไหม` ยังใช้ flow เดิม ไม่ถูกดึงไปคู่มือ

## การ์ดและพรีวิว

- `/app/help`: คู่มือจริงใน MINI App เข้าจากตั้งค่าและภาพรวม ปุ่มอ่านวิธีใช้ไม่เปลี่ยนข้อมูล ปุ่มหน้าที่เกี่ยวข้องใช้ navigation ไป path ที่กำหนดไว้
- `/dev/line-onboarding`: พรีวิวเฉพาะ development สำหรับทบทวน Carousel แบบเลื่อน/แบบรวม ใช้ JSON เดียวกับ `follow` บน production ตอบ 404
- `/dev/line-flex`: คลังกรณีตัวอย่างกว่า 40 แบบ จาก builder จริงและข้อมูลสมมติ ทั้งบันทึก สำเร็จ ยืนยันหลายรายการ OCR รายรับ งบเกิน หมวด บิล ผ่อน รายงาน ค้นหา แต้ม รางวัลหมด แจ้งเตือน ยกเลิก คำขอซ้ำ/หมดอายุ และข้อมูลเปลี่ยน

ทุก postback ในคลังตัวอย่างถูกเปลี่ยนเป็น `preview:*` ก่อนแสดง/คัดลอก ปุ่มจาก JSON ตัวอย่างที่ส่งผ่าน Simulator จึงไม่ใช้บันทึกเงิน ตัวพรีวิวไม่เรียก API บัญชีหรือ LINE ค่า heading ของการ์ดตอบกลับเป็น metadata ของ Answer จากโค้ดระบบ ไม่ได้อนุมานความสำเร็จจากข้อความ AI และไม่ถูกส่งเป็น field แปลกปลอมใน LINE payload

Payload Carousel มี 10 bubbles ขนาดเดียวกัน เทสต์ตรวจต่ำกว่า 50 KB รวมและ 30 KB ต่อ bubble ตาม [LINE Messaging API reference](https://developers.line.biz/en/reference/messaging-api/#flex-message) ภาพเว็บเป็นพรีวิว การแสดงจริงอาจต่างตามระบบและขนาดหน้าจอ

## การตรวจ

มี unit/DB tests สำหรับการเรียกคู่มือหลายสำนวน ปุ่มช่วยเหลือครบ/เต็มเพดาน การส่ง follow ซ้ำ การขอวิธีใช้ระหว่าง pending amount/form/confirmation/edit และการไม่บันทึกตัวอย่างหรือแจกแต้มจากการอ่านคู่มือ ตรวจ MINI App ใน mock mode แยกจาก HTTPS production shell และการใช้ LINE จริง ไม่ส่งข้อความหรือเขียนข้อมูลจริงจากการทดสอบ

ต้องใช้ migration `20261116040000_personal_categories_auto_points.sql` สำหรับแต้ม/หมวด/วิเคราะห์รอบนี้ การ commit/merge ไม่ได้ apply migration บนฐานออนไลน์โดยอัตโนมัติ
