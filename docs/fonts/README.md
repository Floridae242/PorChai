# SanamDeklen_chaya

User-supplied font from `Downloads/SanamDeklen_chaya`, applied to PorChai's
website and MINI App using `next/font/local`. Original font binary is kept at
`app/fonts/SanamDeklen_chaya.otf`; no external font request is needed for it.

Creator credit from the supplied readme: **Chaya XCX**. The original author note
is preserved in [SanamDeklen-chaya-README.jpg](SanamDeklen-chaya-README.jpg).
The package contains one regular face, registered as weight 400; existing bold
UI styles use the browser's synthetic bold rather than claiming a separate font.
