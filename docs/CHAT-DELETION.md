# ลบรายจ่ายผ่าน LINE

- `ลบ 25 บาทออกจากรายจดวันนี้` หรือ `ลบรายการ 25 บาทของวันนี้`: เลือกรายจ่ายตามยอดและวัน ถ้ามียอดซ้ำจะแสดงตัวเลือกก่อน ทุกกรณีต้องตรวจรายการและยืนยันก่อนลบ
- `ลบรายการที่เคยจดในวันนี้ทั้งหมด` หรือ `ลบรายจ่ายทั้งหมดวันนี้`: ตรวจจำนวน ยอดรวม และตัวอย่างรายการก่อนยืนยัน ลบเฉพาะ snapshot ตอนขอ ไม่รวมรายการใหม่ที่จดภายหลัง
- `ไม่เอา` / `ยกเลิก`: ปิดคำขอ ปุ่มยืนยันเดิมใช้ทำซ้ำไม่ได้
- ไม่ระบุวัน เช่น `ลบรายการทั้งหมด` หรือมีเงื่อนไขที่ยังไม่รองรับ เช่น `ลบค่ารถทั้งหมดวันนี้`: ถามขอบเขตก่อน ไม่ขยายไปลบรายการอื่น
- รายรับ งบหมวด และบัญชีเป็นข้อมูลคนละชนิด ไม่ใช้คำสั่งลบรายจ่ายเปลี่ยนข้อมูลเหล่านั้น รายการจากการจ่ายแผน/บิลต้องยกเลิกการจ่ายที่แผนเพื่อให้บัญชีตรงกัน

## ฐานข้อมูลและการติดตั้ง

ใช้ migration `supabase/migrations/20261118000000_chat_entry_batch_cancel.sql` ก่อนเปิดใช้ bulk deletion บน environment นั้น การพัฒนารอบนี้ใช้เฉพาะ local Supabase ยังไม่ได้ apply บน production

RPC `cancel_chat_entries` เรียกได้เฉพาะ service role ตรวจเจ้าของ active cycle วัน และ timestamp ของทุกรายการ พร้อมล็อกแถวและยกเลิกแบบ transaction เดียว ถ้ารายการใดเปลี่ยนไป จะไม่ยกเลิกส่วนที่เหลือ รับ snapshot ครั้งละ 1–100 รายการ การยกเลิกใช้ `cancelled_at` และเก็บ audit history ตาม trigger เดิม ไม่ลบประวัติถาวร

เมื่อยังไม่มี migration จะตอบว่าการลบหลายรายการยังไม่พร้อม และยังเลือกลบทีละรายการได้ ไม่มี fallback ไปบันทึกรายจ่ายใหม่
